##  Selection Page (Practice Simple Project):
    - A simple selection card interface built using HTML and CSS.

##  About the Project:
    - The project displays multiple selection cards for different development and data-related fields.
    - Each card contains a checkbox, title, and description to allow users to select their preferred field.
    - It is designed as a beginner-friendly project to practice HTML labels, check inputs, CSS styling, spacing, and responsible layouts without using Flexbox.

##  Objectives:
    > Practice HTML form elements such as 'label' and 'input',
    > Learn how to connect labels with checkboxes using 'for' and 'id',
    > Learn how to customize default checkboxes using CSS,
    > Understand the use of 'width', 'max-width', 'height', and 'margin:auto',
    > Practice arranging elements using 'display: properties' like 'block', 'inline', and 'inline-block',
    > Learn how to use pseudo-classes such as ':checked',
    > Practice using pseudo-elements such as '::after',
    > Improve CSS organization and styling.
