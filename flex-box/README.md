##  CSS Flexbox Photo Gallery (Practice Project):

    ## About the project:

        > A simple photo gallery built using HTML and CSS,
        > The project displays a collection of images arranged using CSS Flexbox,
        > It is designed as a beginner-friendly project to practice Flexbox layout, spacing, image styling, and hover effects,
        > The gallery is responsive and adjusts the arrangemment of images based on the available screen space.

    ##  Objectives:

        > Practice creating a photo gallery using HTML and CSS,
        > Learn how to create a Flexbox container using 'display:flex',
        > Understand 'flex-direction', 'flex-wrap', 'justify-content', and 'align-items',
        > Practice spacing elements using 'gap',
        > Understand the difference between 'width' and 'max-width',
        > Practice centering a container using 'margin:auto',
        > Learn how to control image dimensions using 'width' and 'height',
        > Practice using 'object-fit:cover' for consistent image sizing,
        > Add simple hover effects using CSS transitions and transform.

    ##  Features:

        > Flex-box based photo gallery,
        > Responsive image layout using flex-wrap,
        > Centered gallery container,
        > Consistent image dimensions,
        > Rounded image corners,
        > Image hover zoom effects,
        > Smooth transition effects,
        > Simple and beginner-friendly design.
